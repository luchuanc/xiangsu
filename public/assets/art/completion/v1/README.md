## 实际接入

`completion-art.ts` 仅替换正式清单中的物理路径和来源记录，保留资源 ID、bundle、尺寸和动画 clip 合同；fixture 清单不受影响。

`BattleArtResources.ts` 为全部怪物提供已审阅立绘，并加载扩展特效纹理。`BattleSceneRenderer.ts` 根据已提交的领域事件播放弹道、范围、斩击、治疗、护盾、状态、复活和召唤效果；支持 1/2 倍速度、降低闪光及 pause/destroy 清理。

背包、技能、羁绊页面消费对应图片。状态和物品图标仍由正式资源 bundle 加载，核心 UI 图集被场景 UI 消费。

## 可重复打包与校验

在项目根目录执行：

```sh
npm run pack:completion-art
npm run verify:completion-art
npm run verify:assets -- --final
npm run build
```

打包脚本只提取、缩放和组合已生成源图，不会再次调用图像生成。人工审核的怪物边界和特效行间隔均固化在脚本中；对被切片边缘截断的小型邻格连通块进行排除，保留完整的内部孢子、漂浮晶体等细节。战斗直接加载 160px 立绘切片，避免解码大尺寸生成原图。

校验涵盖：全量内容引用、占位标识、文件存在性、透明通道、非空图像、装备与战斗资源重复图检测、全部 97 个技能 / 效果的帧及图标覆盖，以及原有正式资源契约。

## 已知范围

- 新怪物高精度立绘用于当前战斗表现；位移、受击与浮字由提交事件驱动。低分辨率兼容图集提供呼吸、突进、蓄力、受击、倒下的立绘变换动画，**并非逐帧手绘肢体动作**。
- 后续楼层遭遇标记采用方向翻转与明暗变化，**并非四视角重绘**。
- 97 个技能 / 效果按类型和元素复用特效家族，并非 97 套独立动画。
- 本轮没有重画后续楼层地图或更换音频。正式清单中这些类别的历史资源状态仍保留，不能据此宣称整个游戏美术均已最终定稿。
