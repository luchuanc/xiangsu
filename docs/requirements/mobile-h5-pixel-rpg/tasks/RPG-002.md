## 精确契约

Schema 必须拒绝未知字段、重复 ID、失效引用、非整数百分比、错误层长度、非法品质/词条池、表外 ComboTagId/SkillFamilyId，以及不是 97 技能/18 状态/10 BossIntent/8 EncounterModifier/10 AbyssEcho 等冻结精确数量的最终内容。`ContentCatalog` 构造成功后只暴露只读 getter 和按 ID 查询；缺失 ID 返回 `DomainResult` 错误 `INVALID_CONTENT`，不返回 `undefined` 后继续。zh-CN 字典必须精确覆盖 LOC-1.2 的 348 个内容名称、206 个说明/任务描述、7 个对话、2 个 lock、34 个 `tag.*`、25 个 `skill_family.*`、3 个技能词条目标分支、12 个 modifier、9 个 skill-affix operation、全部核心 UI/结构化枚举/条件与效果 key 和 41 个错误码展开的 60 个终端模板，模板 token 精确匹配。validationMode 是构造参数而非内容字段：`fixture` 只给单测；`{kind:'batch',batchId:'verticalSlice'|'floors02_05'|'floors06_10'|'abyssEchoes'}` 读取脚本内冻结的累计精确 ID 集；`final` 检查全量，abyssEchoes 累计集合必须与 final 相等。RPG-026 和候选构建只能用 final，任何模式都不能跳过字段/引用/合法池/本地化校验。
