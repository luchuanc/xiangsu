## 精确契约

Scene 接口固定为 `prepare(params)`, `enter(params)`, `pause()`, `resume()`, `exit()`, `destroy()`；`prepare` 只加载资源并构建 detached root，不挂到 stage、不接收输入。路由切换串行化，同一时间只允许一个 transition。`AssetCatalog` 严格读取 ASSET-1.2，逻辑 ID 不存在、尺寸/clip/bundle/source 不符均阻断，不使用通用缺图；音频固定 ogg→mp3 可解码选择，AssetService fetch 后交 AudioService decode/register，并随 bundle 引用卸载。动画按 4.2 的首效果表纯函数派生，其中空 effects 的 passive/effect 必须且只能得到 `passive/physical/0/none/null`，零时长不入队、不调用音频。每组资源加载固定最多 3 次尝试、相邻间隔 250ms（不是首次加 3 次重试），第三次失败返回 `ASSET_LOAD_FAILED` 与 bundleId；只有目标场景 enter 成功后才 exit/destroy 旧场景。涉及存档的业务转场可在 prepare 与 enter 之间执行提交回调。
