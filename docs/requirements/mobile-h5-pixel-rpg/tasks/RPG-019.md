## 精确契约

NPC 交互只读取 `NpcDefinition.function` 路由到固定功能，不根据名称猜测。层数卡按 world 前缀和 `bossRetryUnlockedFloorIds` 展示完整/短程/重试：未首通只允许 exploration，已首通才允许 shortFarm，重试只在已接触且未首通时显示。FloorDefinition 的 phase/shortRoute 字段只展示或传给 service，不在 UI 解析 suffix。守望者回响标签在 storyCompleted 前显示锁定，完成后读取 10 条 AbyssEchoDefinition；实际开始/奖励由 RPG-028 接入。继续游戏按 battle/reward → exploration/shortFarm map → bossRetry/abyssEcho battle → town 解析，COMPLETE 先幂等 cleanup。离城事务按 mode strict 创建，保存失败不留空壳 expedition；只有 exploration/shortFarm 刷新商店。
