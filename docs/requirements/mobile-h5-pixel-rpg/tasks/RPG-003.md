## 精确契约

算法固定为 `xoshiro128**`，状态为 4×uint32。所有 JS 位运算结果立即 `>>> 0`；乘法一律使用 `Math.imul`。

SplitMix32 精确步骤：内部 `x=(x+0x9e3779b9)>>>0`；`z=imul(x^(x>>>16),0x21f0aaad)>>>0`；`z=imul(z^(z>>>15),0x735a2d97)>>>0`；返回 `(z^(z>>>15))>>>0`。单个 uint32 seed 连续调用四次形成 `[s0,s1,s2,s3]`；只有结果全零才替换为 `[0x9e3779b9,0x243f6a88,0xb7e15162,0xdeadbeef]`。

xoshiro 单步：`result=imul(rotl(imul(s1,5),7),9)`；`t=s1<<9`；依次执行 `s2^=s0, s3^=s1, s1^=s2, s0^=s3, s2^=t, s3=rotl(s3,11)`，返回 result。`nextIntInclusive(min,max)` 令 `span=max-min+1`、`limit=floor(2^32/span)*span`，拒绝所有 `draw>=limit` 后返回 `min+(draw%span)`。

`derive(namespace)` 对“当前 s0～s3 各自 4 字节小端表示 + namespace 的 UTF-8 字节”做 FNV-1a 32（offset `0x811c9dc5`、prime `0x01000193`、每字节 xor 后 imul），把 hash 作为新 SplitMix32 seed，且不推进父流。稳定权重总和允许到 `2^32`，与 `nextIntInclusive` 的最大 span 一致。

概率辅助固定为：chanceBps=0/10000 时分别直接 false/true 且不推进 RNG；其余调用 `nextIntInclusive(1,10000)` 并比较 `draw<=chanceBps`。稳定加权抽取使用 `nextIntInclusive(1,sumWeights)` 并按原数组累计权重选择。不得在各领域重新实现另一套边界。

固定向量（十进制 uint32）必须逐项断言：seed `0x12345678` 初始状态 `[2986037511,744488920,2204577711,2810942300]`；前 20 个输出为 `[1878818782,786455212,462225631,2155212579,411377898,3167696138,1785522653,3592849924,609211532,3713860673,3931107074,3110254264,3169712676,3032225663,45091845,1211551780,185791654,443690745,1454244678,2582382595]`；输出后状态 `[3436654534,1636222966,3049801367,838880439]`；对初始状态 derive(`loot`) 的 FNV hash 为 `3284357482`、派生初始状态 `[195995783,4150676434,722383666,719531309]`。领域创建时间与实例/事务 ID 只能来自 `DomainContext` 注入，不直接读 `Date.now()`、`crypto.randomUUID()` 或 `Math.random()`。生产 IdFactory 精确输出 `<kind>_<uuid>`，kind 只允许 `eq|stone|exp|battle|root|event|reward`，uuid 由适配器调用 `crypto.randomUUID()` 产生且必须是小写 RFC 4122 v4；测试 factory 按 kind 输出固定单调序列。RPG-003 负责证明分配结果可由 candidate 持有；“保存重试不得重新调用 factory”必须在首个真实事务边界 RPG-004 用 SaveCoordinator spy 验证，禁止在本卡用局部对象自证。跨刷新/跨类型不得碰撞。所有核心注释使用中文。
