## 目标

实现移动端全屏游戏菜单、背包/装备/三候选铁匠、酒馆编队招募、技能导师/铭石/调谐专注、Combo 首获、卡点诊断和设置页面，以点击选择—预览—确认完成全部核心管理操作。

- 不实现商店和铁匠的完整视觉皮肤，也不改领域规则。

## 精确契约

每个页面从 GameStore 投影只读 ViewModel，编辑内容保存在局部 draft；点击确认前调用领域 preview，ComboScreen 展示新增/失去以及 stackRule 来源。重铸候选只显示领域 ReforgePreviewV1；百分比分母和克制跃迁按 UI 规格。野外消耗品只通过 UseFieldItemCommandV1 对当前队伍内存活未满血角色使用；战斗物品只走 BattleCommandV1，不能从背包旁路。首次 Combo 成功持久化后才追加 discoveredComboIds 并播放首获卡及一次 `sfx_combo_unlock`；失败或再次装备已发现 Combo 不播放。确认命令只有成功持久化后才替换 Store；失败保留 draft 和错误。主要点击目标不小于 48 CSS px，间距不小于 8px。
