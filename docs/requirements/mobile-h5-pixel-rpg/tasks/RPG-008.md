## 精确契约

等级范围 1～50；xp 是累计总经验，50 级钳制 75460。每级属性由定义中的基础值与成长值按 `game-design.md` 公式计算。正常升级仅在原 currentHp>0 时补偿最大生命增长量，倒地者保持 0，技能点每级增加 1。`createCaughtUpRecruit(characterId, protagonistLevel)` 则固定写等级阈值 xp、level-1 点、满生命和全空 loadout；所有 ID 和引用必须由 ContentCatalog 验证，不读取别名或缺省成长字段。
