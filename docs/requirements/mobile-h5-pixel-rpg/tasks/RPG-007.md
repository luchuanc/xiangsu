## 目标

实现按 `pointerId` 独占的动态摇杆、触控按钮和统一输入快照，使双指移动与交互可以并行，并在暂停、失焦或指针取消时立即归零。

## 非目标

- 不实现探索移动、NPC 交互或战斗指令。
- 不用 DOM 手势库，也不把拖拽作为背包等核心操作。

## 精确契约

`InputState.snapshot()` 每固定步返回归一化移动向量、一次性动作集合和递增帧号。摇杆只接受其起始 `pointerId`，按钮也只消费自身捕获的指针；`pointerup`、`pointercancel`、`blur`、`visibilitychange`、竖屏、WebGL context lost 和路由暂停均调用 `resetAll()`。长按优先以事件 CSS 坐标计算位移；若使用逻辑坐标则阈值固定为 `ceil(8/scale)`，超过即取消。
