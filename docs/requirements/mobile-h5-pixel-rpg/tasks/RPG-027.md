## 目标

在第一层纵切片已可玩的前提下，实现已首通层短程刷取、首通前 Boss 重试点和仅限已清层普通/精英的重复指令辅助，降低移动 H5 跑图与点击负担，同时封住无跑图 Boss 农场和自动消耗高价值资源。

## 非目标

- 不做自动战斗 AI、离线挂机、扫荡、战斗加速到 ×4 或 Boss 自动操作。
- 不把第一层首个 Combo/指定词条改成保底。
- 不实现深渊回响；只提供 RPG-028 复用的 mode/直入战斗基础。

## 精确契约

shortFarm 只在已首通层创建，物化 FloorDefinition.shortRouteObjectIds 的 3 normal+1 elite+1 chest 与 return portal；完成不产 Boss/首通/echoCharges。exploration 首次成功创建未首通 Boss 战时原子追加 bossRetryUnlockedFloorIds；bossRetry 仅在该 Boss 未首通时直入真实 encounter，使用正常 Boss/首通奖励，胜败后回城且不增加 echoCharges，首通后入口隐藏。battleAssist 只在已首通层 normal/elite 运行，记录 basic 或 active，不记录 target/ultimate/item/defend/retreat；350ms 内任何触摸取消，active 不合法只降级 basic，目标排序逐字段按 GAME-1.2 5.6。
