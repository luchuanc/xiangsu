## 精确契约

Application 选项与 `plan.md/PixiJS 运行时` 一致。`ViewportService` 输出 `{scale, offsetX, offsetY, safeRect, blockedReason}`，允许小数 CSS contain；HitAreaService 输出经 ceil 换算的 48/8 CSS px 逻辑门槛。竖屏或低于 568×320 时 ticker 停止、输入恢复回调不执行；横屏恢复先 resize/布局/渲染一帧，再通知输入层。`webglcontextlost` 要 preventDefault 并暂停 ticker/输入/音频、显示遮罩；restored 后由 RPG-006 的资源层重传当前 bundle，再从 GameStore 重建 View。AudioService 只接受 ASSET-1.2 的封闭 music/sfx ID，按 baseGain×用户音量×场景倍率计算，不解释领域事件；调用方严格按 ASSET-1.2 4.4 路由。

RPG-001 延期到本卡的启动生命周期责任：同页重复调用启动入口不得创建重复 Application/canvas 或重复注册监听；初始化失败后必须允许显式重试，不能永久缓存 rejected Promise。销毁后再次启动必须创建一个干净实例。
