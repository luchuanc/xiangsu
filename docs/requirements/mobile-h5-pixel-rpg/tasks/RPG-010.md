## 精确契约

装备底材使用 `equipmentBasePools` 固定先按六部位等权、再按部位内底材等权，两级均消费 RNG，不能平铺底材。品质词条数固定为 0/2/3/4/4+1；同件不重复 affixId 或 exclusiveGroup。`tempered`/`exalted` 分别选择 1/2 个合法普通词条，将实例随机值乘 125% 后向下取整；指定 fixed craftGrade 先抽足合法强化词条再补齐普通词条。随机/weighted/指定固定装备必须分别遵守 `balance-tables.md` 5.6 的消费顺序，闭区间 min=max 也抽一次。重铸首次 Open 固化普通槽，以 contentVersion/instanceId/index/reforgeCount 派生最多 3 个不同 ID 候选；刷新/取消不扣料，Confirm 重派生核对后才扣料并 +1。装备/铭石实例初始 reforgeCount=0；生成池为空返回配置错误，不能降级生成。`FieldItemService` 只接受 `expedition!=null && battle==null`、匹配当前 revision、拥有 field context 消耗品且目标为当前队伍内 `0<HP<maxHp` 的已招募角色；城镇、战斗中和错误 context 精确返回 ITEM_USE_FORBIDDEN 三个 reason，不能挪用 NOT_IN_TOWN/INVALID_BATTLE_PHASE。首版只执行单一 maxHp 比例、不可暴击的 HealEffect。扣除 1 件与钳制回血必须在同一 SaveCoordinator 事务中，失败不推进探索步数、保护计数或 RNG；净化药剂不得在野外使用。
