## 精确契约

EnemyAi 只根据当前 BattleSnapshot、AI 定义和 battle RNG 产生合法 BattleCommand；Boss 在 FloorDefinition 狂暴回合使用 priority120 通用规则。胜出 skill 命中 BossIntentDefinition 时建立 `action_declare_intent` 稳定根行动，下一次合法行动释放；狂暴优先、控制只延后、读档保留。BattleFactory 按 encounter.modifierIds 应用 8 类无 RNG 通用规则。创建战斗按初始槽位、召唤按稳定根行动追加 discoveredEnemyIds。胜利奖励的 source 必须逐项匹配 mode 与 source 判别分支，用 `rewardTransactionId` 幂等地同时提交经验、金币、材料、装备/铭石和相关进度；出战倒地者先以 1 HP 复苏再应用本次升级最大生命增量。RewardService 接受 strict encounter/chest/abyssEcho source 并执行 9999/120/80/30 dry-run；echo 细节在 RPG-028 接入，领域框架不得为其猜默认值。
