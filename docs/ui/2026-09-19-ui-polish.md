# 像素远征 · UI 精修记录

本轮直接修改现有 PixiJS / TypeScript 项目，沿用像素美术和游戏流程，以深夜蓝、古铜金、青绿色建立统一界面层级。没有增加运行依赖或改变存档格式。

## 交付

- 标题页改为左侧标题与操作区、右侧城镇夜景；根据是否存在存档突出主按钮，无存档时解释禁用原因。视觉按钮和 DOM 命中层继续共用安全区布局。
- 冒险菜单改为五张功能卡片，展示说明和真实装备、同伴、羁绊数量；页头展示金币与已解锁楼层。568×320 横屏可直接看到全部入口。
- 背包、队伍、技能和羁绊界面统一字体、边框、卡片、选中态、禁用态与固定返回栏；确认操作使用金色强调。
- 系统设置提供带解释的开关和 `aria-checked` 状态，继续通过原有保存事务提交。重绘后保留同页滚动位置和可用按钮的键盘焦点。
- 奖励页统一战利品卡片、品质颜色和领取按钮；仍读取原有已保存奖励事务。
- Pixi 的标题、城镇弹窗、战斗和探索 HUD 使用统一中文字体。探索工具按钮保持至少 44 个逻辑像素的排版空间，修复桌面缩放时图标与文字拥挤；安全区预检同步该下限。
- 提供统一 SVG 导航图标、鼠标反馈、可见键盘焦点、降低动态效果支持、横屏提示。背景资源加载失败时使用不透明底色。

## 验证

- 最终 `npm run build` 通过，包含 TypeScript 检查。
- `npm run lint` 通过。
- 全量单测：99 文件、652 项，首轮 647 项通过，5 项失败。两项旧标题坐标断言已改为共享布局常量；三项场景／资源生命周期测试超时。随后对这五项执行定向复测，全部通过，未调整超时阈值。不能将其表述为一次全量运行全部通过。
- 最终标题、共享按钮、视口组件回归：18 / 18 通过。
- 真实移动浏览器 E2E：3 / 3 通过，覆盖标题与新游戏、摇杆到达制图师、打开楼层面板并进入第一层。
- 浏览器补充验收：568×320、844×390、1440×900；五个管理页面无横向溢出、返回栏在可见区域、所有已测可见按钮至少 44×44 CSS 像素。
- 设置重载持久化、空格键操作开关后保留焦点、确认编队后保留滚动位置均通过；390×844 正确显示横屏提示；该验收过程没有捕获到控制台错误或页面异常。

运行环境先按锁文件执行 `npm ci --no-audit --no-fund`，补齐 Intel Mac 的原生依赖，最终 PixiJS 为锁定的 8.19.0。锁文件未修改。E2E 使用本机已有 Chromium，通过 output 下的临时测试配置指定路径，未修改项目的 Playwright 配置。
